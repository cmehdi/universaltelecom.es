# Universal Telecom - Static HTML Site

This folder contains pure HTML/CSS/JS versions of the Universal Telecom website in three languages: Spanish, English, and French.

## Structure

\`\`\`
new/
├── css/
│   └── styles.css          # Global styles
├── js/
│   └── main.js            # JavaScript functionality
├── images/                 # Images folder (to be populated)
├── es/                    # Spanish pages
│   ├── index.html
│   ├── centralita-virtual.html
│   ├── whatsapp-api.html
│   └── ...
├── en/                    # English pages
│   ├── index.html
│   ├── virtual-pbx.html
│   ├── whatsapp-business-api.html
│   └── ...
└── fr/                    # French pages
    ├── index.html
    ├── standard-virtuel.html
    ├── whatsapp-business-api.html
    └── ...
\`\`\`

## Features

- Pure HTML/CSS/JS - No frameworks or build tools required
- Responsive design - Mobile-first approach
- Multi-language support - ES, EN, FR
- SEO optimized - Semantic HTML and meta tags
- Fast loading - Minimal dependencies
- Easy to deploy - Static files ready for any web server

## Deployment

1. Copy all files to your web server
2. Ensure images are placed in the `/images` folder
3. Configure your web server to serve the appropriate language based on URL or browser settings
4. Set up proper redirects if needed
