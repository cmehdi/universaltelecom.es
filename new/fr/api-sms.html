Envoyer des SMS en Masse

const UniversalTelecom = require('universal-telecom');

const client = new UniversalTelecom({
  apiKey: 'votre_cle_api',
  apiSecret: 'votre_secret_api'
});

// Liste de numéros
const recipients = [
  '+34612345678',
  '+34623456789',
  '+34634567890'
];

// Envoyer à tous
const promises = recipients.map(number => {
  return client.messages.create({
    from: '+34900123456',
    to: number,
    body: '🎉 Soldes d\'été! -50% sur tous nos produits. Code: ETE50. Offre valable jusqu\'au 31/08.'
  });
});

Promise.all(promises)
  .then(messages => {
    console.log(`${messages.length} SMS envoyés avec succès!`);
    messages.forEach((msg, i) => {
      console.log(`${i + 1}. ${msg.to}: ${msg.status}`);
    });
  })
  .catch(error => {
    console.error('Erreur:', error.message);
  });
from universal_telecom import Client
import concurrent.futures

client = Client(
    api_key='votre_cle_api',
    api_secret='votre_secret_api'
)

# Liste de numéros
recipients = [
    '+34612345678',
    '+34623456789',
    '+34634567890'
]

def send_sms(number):
    return client.messages.create(
        from_='+34900123456',
        to=number,
        body='🎉 Soldes d\'été! -50% sur tous nos produits. Code: ETE50. Offre valable jusqu\'au 31/08.'
    )

# Envoi parallèle
with concurrent.futures.ThreadPoolExecutor(max_workers=10) as executor:
    messages = list(executor.map(send_sms, recipients))
    
print(f'{len(messages)} SMS envoyés avec succès!')
for i, msg in enumerate(messages, 1):
    print(f'{i}. {msg.to}: {msg.status}')

Recevoir des SMS avec Webhooks

const express = require('express');
const bodyParser = require('body-parser');

const app = express();
app.use(bodyParser.json());

// Endpoint pour recevoir les webhooks
app.post('/sms/received', (req, res) => {
  const incomingSMS = req.body;
  
  console.log('SMS reçu!');
  console.log('De:', incomingSMS.from);
  console.log('À:', incomingSMS.to);
  console.log('Message:', incomingSMS.body);
  console.log('Date:', incomingSMS.dateReceived);
  
  // Traiter le SMS (ex: réponse automatique)
  if (incomingSMS.body.toUpperCase() === 'OUI') {
    console.log('Confirmation reçue du client');
    // Envoyer une réponse automatique
    client.messages.create({
      from: incomingSMS.to,
      to: incomingSMS.from,
      body: 'Parfait! Votre rendez-vous est confirmé. À bientôt!'
    });
  }
  
  // Répondre au webhook
  res.status(200).json({ received: true });
});

app.listen(3000, () => {
  console.log('Serveur webhook démarré sur le port 3000');
  console.log('URL: http://votre-serveur.com:3000/sms/received');
});

Questions Fréquentes

Quel est le taux de délivrabilité?

Notre taux de délivrabilité est de 99,9% grâce à nos connexions directes avec plus de 800 opérateurs dans le monde. En cas d'échec, nous basculons automatiquement vers un opérateur alternatif.

Quelle est la vitesse de livraison?

La vitesse moyenne de livraison est de moins de 3 secondes. Les SMS prioritaires (comme les codes 2FA) peuvent être livrés en moins d'1 seconde.

Puis-je envoyer des SMS en masse?

Oui! Notre infrastructure supporte jusqu'à 10 000 SMS par seconde. Idéal pour les campagnes marketing à grande échelle.

Comment fonctionne la facturation?

Vous ne payez que pour les SMS effectivement livrés. Pas de frais mensuels, pas de minimum, pas de frais cachés. Facturation mensuelle avec remises sur volume automatiques.

Puis-je recevoir des SMS?

Oui! Les SMS bidirectionnels sont inclus gratuitement. Configurez un webhook pour recevoir les réponses de vos clients en temps réel.

Y a-t-il des limites d'envoi?

Les nouveaux comptes ont une limite de 100 SMS/heure les premières 24h pour prévenir les abus. Cette limite est automatiquement levée après vérification.

Puis-je utiliser mon propre numéro?

Oui, vous pouvez porter vos numéros existants ou acheter de nouveaux numéros depuis notre plateforme. Activation en moins de 24h.

Comment programmer un SMS?

Utilisez le paramètre "scheduleTime" dans votre requête API. Vous pouvez programmer jusqu'à 30 jours à l'avance avec gestion automatique des fuseaux horaires.

Puis-je personnaliser l'expéditeur?

Oui! Utilisez un nom alphanumérique (ex: "UnivTel") ou un numéro dédié. Les noms alphanumériques ne permettent pas de recevoir des réponses.

Y a-t-il un environnement de test?

Oui, notre sandbox est 100% gratuit et illimité. Testez toutes les fonctionnalités sans frais avant de passer en production.

Comment suivre les SMS envoyés?

Chaque SMS reçoit un ID unique. Utilisez notre API de statut ou configurez des webhooks pour recevoir des mises à jour en temps réel (envoyé, livré, lu, échoué).

Respectez-vous le RGPD?

Oui, nous sommes 100% conformes au RGPD. Toutes les données sont hébergées en Europe et chiffrées. Certifications ISO 27001 et SOC 2 Type II.
