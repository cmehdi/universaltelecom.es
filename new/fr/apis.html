Exemples de Code - API Voix

Passez un appel en quelques lignes de code

const UniversalTelecom = require('universal-telecom');

const client = new UniversalTelecom({
  apiKey: 'votre_cle_api',
  apiSecret: 'votre_secret_api'
});

// Passer un appel
client.calls.create({
  from: '+34900123456',
  to: '+34612345678',
  url: 'https://votre-serveur.com/call-flow.xml'
})
.then(call => {
  console.log('Appel initié:', call.sid);
  console.log('Statut:', call.status);
})
.catch(error => {
  console.error('Erreur:', error.message);
});
from universal_telecom import Client

client = Client(
    api_key='votre_cle_api',
    api_secret='votre_secret_api'
)

# Passer un appel
call = client.calls.create(
    from_='+34900123456',
    to='+34612345678',
    url='https://votre-serveur.com/call-flow.xml'
)

print(f'Appel initié: {call.sid}')
print(f'Statut: {call.status}')
<?php
require_once 'vendor/autoload.php';

use UniversalTelecom\Rest\Client;

$client = new Client(
    'votre_cle_api',
    'votre_secret_api'
);

// Passer un appel
$call = $client->calls->create(
    '+34612345678',
    '+34900123456',
    [
        'url' => 'https://votre-serveur.com/call-flow.xml'
    ]
);

echo "Appel initié: " . $call->sid . "\n";
echo "Statut: " . $call->status . "\n";
?>
curl -X POST https://api.universaltelecom.com/v1/calls \
  -u "votre_cle_api:votre_secret_api" \
  -H "Content-Type: application/json" \
  -d '{
    "from": "+34900123456",
    "to": "+34612345678",
    "url": "https://votre-serveur.com/call-flow.xml"
  }'

Exemples de Code - API WhatsApp

Envoyez un message WhatsApp avec un template

const UniversalTelecom = require('universal-telecom');

const client = new UniversalTelecom({
  apiKey: 'votre_cle_api',
  apiSecret: 'votre_secret_api'
});

// Envoyer un message WhatsApp
client.whatsapp.messages.create({
  from: 'whatsapp:+34900123456',
  to: 'whatsapp:+34612345678',
  template: {
    name: 'order_confirmation',
    language: 'fr',
    components: [
      {
        type: 'body',
        parameters: [
          { type: 'text', text: 'Jean Dupont' },
          { type: 'text', text: '#ORD-12345' }
        ]

    ]
  }
})
.then(message => {
  console.log('Message WhatsApp envoyé:', message.sid);

.catch(error => {

Questions Fréquentes

Quelle est la disponibilité de vos APIs?

Nos APIs ont un SLA de 99,95% de disponibilité. Nous avons une infrastructure redondante dans plusieurs régions pour garantir un service ininterrompu.

Y a-t-il des limites de taux?

Oui, les limites par défaut sont de 100 requêtes par seconde par clé API. Si vous avez besoin de limites plus élevées, contactez notre équipe commerciale.

Puis-je tester les APIs gratuitement?

Oui! Tous les nouveaux comptes reçoivent 100€ de crédits gratuits. Vous pouvez également utiliser notre environnement sandbox sans frais.

Comment fonctionne la facturation?

Vous ne payez que pour ce que vous utilisez. La facturation est mensuelle et détaillée. Vous pouvez définir des alertes de budget dans votre tableau de bord.

Offrez-vous un support technique?

Oui, support 24/7 par chat, email et téléphone. Notre équipe d'ingénieurs répond généralement en moins de 2 heures.

Les APIs sont-elles conformes au RGPD?

Oui, toutes nos APIs sont 100% conformes au RGPD. Nous sommes certifiés ISO 27001 et SOC 2 Type II.

Puis-je utiliser mon propre numéro de téléphone?

Oui, vous pouvez porter vos numéros existants ou acheter de nouveaux numéros directement depuis notre plateforme.

Quels langages de programmation supportez-vous?

Nous avons des SDKs officiels pour Node.js, Python, PHP, Ruby, Java, C# et Go. Les APIs REST peuvent être appelées depuis n'importe quel langage.
