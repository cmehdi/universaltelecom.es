Voice API - Make a Call

const axios = require('axios');

const makeCall = async () => {
  const response = await axios.post('https://api.universaltelecom.com/v1/calls', {
    from: '+34900123456',
    to: '+34612345678',
    url: 'https://yourapp.com/voice-instructions.xml',
    method: 'POST',
    record: true
  }, {
    headers: {
      'Authorization': 'Bearer YOUR_API_KEY',
      'Content-Type': 'application/json'
    }
  });
  
  console.log('Call initiated:', response.data);
  return response.data;
};

makeCall();
import requests

def make_call():
    url = 'https://api.universaltelecom.com/v1/calls'
    headers = {
        'Authorization': 'Bearer YOUR_API_KEY',
        'Content-Type': 'application/json'
    }
    data = {
        'from': '+34900123456',
        'to': '+34612345678',
        'url': 'https://yourapp.com/voice-instructions.xml',
        'method': 'POST',
        'record': True
    }
    
    response = requests.post(url, json=data, headers=headers)
    print('Call initiated:', response.json())
    return response.json()

<?php
$curl = curl_init();

Frequently Asked Questions

Do I need a credit card to start testing?

No. You can sign up for free and test all our APIs in sandbox mode without providing payment information. When you're ready to go live, you can add your billing details.

What are the rate limits?

Our default rate limits are 100 requests per second for SMS API, 50 requests per second for Voice API, and 20 requests per second for WhatsApp API. Higher limits are available for verified accounts and enterprise customers.

Which programming languages do you support?

Our APIs are REST-based and work with any programming language that can make HTTP requests. We provide official SDKs for Node.js, Python, PHP, Ruby, Java, C#, and Go.

How do I get my API keys?

After signing up, you'll find your API keys in the dashboard under Settings > API Credentials. You'll get separate keys for sandbox and production environments.

What is your SLA?

We guarantee 99.95% uptime for all our APIs. If we don't meet this SLA, you're eligible for service credits. Full SLA details are available in your service agreement.

Can I test without sending real messages?

Yes! Our sandbox environment allows you to test all API functionality without sending actual SMS messages or making real phone calls. Perfect for development and testing.

How do webhooks work?

Webhooks allow you to receive real-time notifications for events like message delivery, call status changes, or errors. You provide a URL, and we'll POST the event data to it.

What about data security and compliance?

All data is encrypted in transit and at rest. We're SOC 2 Type II certified and compliant with GDPR, HIPAA (for healthcare customers), and PCI DSS requirements.
